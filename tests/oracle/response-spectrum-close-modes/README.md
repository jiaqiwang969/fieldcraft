# Close-mode SRSS and CQC response spectrum

A unit mass has two orthogonal spring directions with angular frequencies 13.87 and 13.93 rad/s. A constant unit pseudo-acceleration spectrum is sampled over both modal frequencies at damping ratio 0.05. The independent modal ordinates are a=0.5/13.87^2 and b=0.5/13.93^2. SRSS and CQC are compared in both signed coordinate directions. The CQC coefficient from Der Kiureghian (1981) is rho=0.9981378742866094.
