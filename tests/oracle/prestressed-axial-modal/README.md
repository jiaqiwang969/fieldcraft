# Prestressed axial mode and unloaded control

This case is the exact discrete solution of two one-metre, unit-area linear-interpolation segments with consistent mass (E = 1,000,000 Pa, density = 1 kg/m³), fixed at their outer ends and coupled through one axial centre coordinate. It is not the continuum fixed-fixed rod: the corresponding 2 m continuum rod has first axial frequency `sqrt(E/rho)/(2L) = 250 Hz`, while the unloaded two-segment discrete value is 275.664447711 Hz, 10.27% higher.

A 1,000 N cut force is locked before the frequency step. The exact reduced mass is `M = 2/3 kg`; the prestressed tangent is `K = 2(E + F) = 2,002,000 N/m`, where `F` is the initial-stress stiffness term, giving `f = sqrt(K/M)/(2π) = 275.802245494 Hz`. The zero-force control gives `K = 2E` and `f = 275.664447711 Hz`. The prestress raises the discrete first frequency by `sqrt(1.001) − 1 = 5.0e-4`, which this case's tolerance resolves. These equations are the closed-form axial perturbation equations described by Bathe, *Finite Element Procedures*, 2nd ed. (2014), §6.8.2.
