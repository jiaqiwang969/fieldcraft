# Undamped single-degree-of-freedom step response

A unit mass and a stiffness of 4 N/m receive a unit step force. The average-acceleration Newmark method uses dt=0.001 s. The independent solution is u(t)=(F/k)(1-cos(omega t)) and v(t)=(F/(m omega))sin(omega t), with omega=sqrt(k/m)=2 rad/s. The three reported times are explicit output frames.
