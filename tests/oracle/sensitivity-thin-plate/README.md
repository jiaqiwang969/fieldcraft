# Thin plate strip sensitivities

A four-by-one clamped shell strip carries a transverse tip load. The case differentiates shell thickness and Poisson ratio in static bending and the first two frequencies.

The independent reference is Kirchhoff plate theory, D = E t^3/[12(1-nu^2)]: t d w/dt / w = -3, t d f/dt / f = 1, nu d w/dnu / w = -2 nu^2/(1-nu^2), and nu d f/dnu / f = nu^2/(1-nu^2). The declared 50--80% bands record the known shear-deformation and four-by-one mesh differences rather than claiming a continuum benchmark at this coarse resolution.
