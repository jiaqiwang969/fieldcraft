# Two-degree-of-freedom modal step response

Two unit masses are independent in the x direction with stiffnesses 1 and 4 N/m. A unit step is applied to both. The modal transient keeps both modes, so the independent closed-form displacements are u1=1-cos(t) and u2=(1-cos(2t))/4. The recipe probes both coordinates at 0.5 s and 1 s.
