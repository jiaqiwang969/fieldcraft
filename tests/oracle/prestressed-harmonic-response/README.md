# Harmonic response about a prestressed equilibrium

The two equal axial segments from the modal case are locked after F = 1000 N. A unit force excites the centre at 100 Hz with mass-proportional damping α = 2. The closed-form scalar impedance is `Z = K − ω² M + i ω α M`, with `K = 2,002,000 N/m`, `M = 2/3 kg`, `ω = 2π·100`; the amplitude is `1/|Z| = 5.75105714843e-07 m` and the phase for `Re(U exp(iωt))` is `atan2(−ωαM, K − ω²M) = -0.000481799455651 rad`. This is the standard single-degree-of-freedom harmonic solution (Vandiver, MIT 2.003SC, lectures 24–25).
