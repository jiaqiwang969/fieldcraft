# Harmonic response about a prestressed equilibrium

This uses the same two-segment, linear-interpolation, consistent-mass discrete model as the modal case; its reference is the model's exact one-coordinate impedance, not a continuum rod approximation. The two equal axial segments are locked after `F = 1000 N`. A unit force excites the centre at 100 Hz with mass-proportional damping `α = 2`. The impedance is `Z = K − ω² M + i ω α M`, with `K = 2,002,000 N/m`, `M = 2/3 kg`, and `ω = 2π·100`; the amplitude is `1/|Z| = 5.75105714843e-07 m` and the phase for `Re(U exp(iωt))` is `atan2(−ωαM, K − ω²M) = -0.000481799455651 rad`. Removing the initial-stress term changes the 100 Hz amplitude by `1.15e-3` relative, so the tolerance resolves the prestress effect. The `F` term in `K = 2(E + F)` is the initial-stress stiffness. This is the standard single-degree-of-freedom harmonic solution (Vandiver, MIT 2.003SC, lectures 24–25).
