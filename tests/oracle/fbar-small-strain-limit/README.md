# Small-strain F-bar limit

Two identical pairs of Hex8 elements in series are extended by 1e-6 m. The
left, bottom and z faces are constrained and the right face is prescribed. One
pair uses the nonlinear reference-volume F-bar formulation and the other uses
the linear volume-averaged B-bar formulation. With Poisson ratio zero, the
independent affine solution gives the middle-plane displacement
0.5e-6 m; the two formulations should agree at this small strain.

This is a uniform extension with Poisson ratio zero, so the volumetric strain is constant everywhere and averaging it gives the same result. It therefore shows the two formulas coinciding in a uniform state only; the nonuniform small-strain limit is checked by the added Cook membrane quantity.
