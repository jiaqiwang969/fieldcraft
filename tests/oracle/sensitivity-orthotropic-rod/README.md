# Orthotropic axial modulus sensitivity

A single hexahedral solid with engineering constants is guided to axial motion and loaded along material axis 1. The case differentiates E1 in static and frequency analyses.

With zero Poisson couplings and fixed density, independent uniaxial algebra gives u proportional to 1/E1 and f proportional to sqrt(E1). The one-element mesh is intentional: these are discrete scaling identities, not an isotropic approximation.
