# Frequency identification of density

The same two-element consistent axial rod has E=1000 Pa, density 1 kg/m³, length 1 m, area 1 m², and fixed node x=0. After the fixed node is removed, `K=(EA/h)[[2,-1],[-1,1]]`, `M=(rho*A*h/6)[[4,1],[1,2]]`, h=0.5 m, and the determinant is `7 lambda² − 240000 lambda + 576000000 = 0` at rho=1. The base frequencies are 8.110128166520553 Hz and 28.331839147600448 Hz. The observations are these frequencies divided by `sqrt(1.44)`, so the closed-form target is rho=1.44 kg/m³.
