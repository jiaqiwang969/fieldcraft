# Axial force and opening of a pretension cut

Two unit-area, one-metre axial elastic segments (E = 1,000,000 Pa) are fixed at their outer ends. A cut at their interface receives a generalized pretension force F = 1,000 N. The closed-form series compliance is

`q = F (L1/(E A) + L2/(E A)) = 1000 (1/1e6 + 1/1e6) = 0.002 m`.

Equilibrium gives section force F on each side. The recipe uses a continuous two-cell hexahedral mesh and a planar internal cut; the reference is the elementary axial-bar solution, independent of this solver.
